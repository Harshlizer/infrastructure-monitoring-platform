# PowerShell Collectors

This folder contains sanitized PowerShell examples from the monitoring platform.

The scripts are grouped by monitoring domain so the project is easier to review:

- `active-directory` for AD, LDAP, certificate, and Group Policy collectors
- `backup` for cloud backup validation checks
- `dns` for DNS monitoring
- `microsoft365` for Microsoft 365 usage and cost analytics
- `server-health` for firewall, reboot, and software inventory collection
- `web` for certificate validation of web endpoints
- `utilities` for supporting operational scripts

All files in this repository are showcase-safe examples. Internal names, secrets, paths, credentials, IDs, and localized text have been removed or generalized.
