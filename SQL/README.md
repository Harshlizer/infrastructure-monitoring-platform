# SQL Layer

This folder contains sanitized SQL scripts used by the monitoring platform.

The scripts are organized by purpose:

- `schema` for database objects required by collectors
- `migrations` for changes to existing objects
- `permissions` for role and access configuration
- `queries` for operational data checks
- `maintenance` for cleanup and retention routines

These scripts are intentionally sanitized for portfolio use. Internal server names, credentials, identifiers, and environment-specific values have been replaced with placeholders.
